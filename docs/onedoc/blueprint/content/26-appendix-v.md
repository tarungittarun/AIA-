# Appendix W — Accessibility annotations per screen (traversal contracts)

Format: traversal order is the focus order; every row = one a11y node with (role, label source, actions). Full tables live in the registry CSV's `a11y` column; this appendix pins the editor and the two riskiest screens.

## W.1 Editor (OD-EDIT-001/002)

Order: app-bar(back: "Back", title, undo, redo, overflow) → page content as block list (each block: role "text field"/"heading N"/"list item"; label = text content with mark prefixes "bold, "; actions: format menu, move up, move down, duplicate, delete) → selection toolbar nodes when visible (each with state on/off) → assistant row (each verb + availability reason) → tab row (4 tabs, selected state). Rules: table blocks expand to cell matrix (rows×cols collection); image blocks announce alt text or "image, no description yet"; page-break guides are non-focusable; IME compose region announced as "composing text".

## W.2 Pack manager (OD-AI-001)

Order: app bar → education/empty card (if no packs) → pack rows (label = name+capability+language; state = verified/unverified/failed; actions: install, verify details, delete) → install button (SAF flow). Failure state announces both hashes (UX-48) via live-region polite.

## W.3 Version restore (OD-FILE-001)

Order: app bar → list (label = kind + relative time + size; state = kind) → preview action → restore action (announces "Your current text will be saved as a version first"). Preview mode announces "previewing version from {time}; back to return".
