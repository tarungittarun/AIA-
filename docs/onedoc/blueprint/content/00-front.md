# OneDoc — Application Development Blueprint

**Version 1.0 — the complete build contract for an autonomous AI developer.**

OneDoc (`app.onedoc`) is an offline document studio for Android: write, structure, format, scan, dictate, listen, and export — with no account, no network, no ads, and no exceptions. This document is written to be executed, not admired: an AI agent given only this repository and this PDF must be able to produce a fully tested, release-quality APK without asking a single clarifying question.

Every requirement has an ID (F-xxx, UX-xxx, C-n, L-n). Every ID maps to at least one automated test case. Every chapter states not just *what* to build but *how to prove it works*. Verification is not a phase at the end; it is the shape of the whole program.

**Reading rule for the agent:** you may not write production code for a chapter you have not read. The reading order is in §29.1; the gates that enforce it are in Part X.
